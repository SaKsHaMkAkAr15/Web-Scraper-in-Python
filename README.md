 Web Scraper 

 Working:
A Python web scraper that extracts book titles, prices, and ratings from books.toscrape.com and saves the data to a CSV file.

 Features:
i) Scrapes 20 books from the website
ii) Extracts title, price and rating of each book
iii) Saves all data to a CSV file automatically

 How to run
1. Make sure Python is installed
2. Install required libraries: pip install requests beautifulsoup4
3. Run this command:
python scraper.py
4. Check books.csv for the scraped data

 Tech used
- Python
- Requests
- BeautifulSoup4
- CSV module
